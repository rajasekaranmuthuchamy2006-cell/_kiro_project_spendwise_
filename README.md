# SpendWise – Smart Expense Tracker

A personal finance tracker built with pure HTML, CSS, and JavaScript. No frameworks, no installation — just open and use.

## Features

- Add, edit, and delete income and expense transactions
- Budget management with progress bar and warning alerts (warn at 80%, exceeded at 100%)
- Category breakdown chart with visual percentage bars
- Monthly summary view grouped by month
- Real-time search and filter by type and category
- All data saved automatically in localStorage — survives page reload

## How to Use

1. Download or clone this repository
2. Open `index.html` in any browser
3. Start tracking your expenses!
